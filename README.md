CrashLens

A developer tool designed to make crash logs actually understandable.

Instead of this:

java.lang.NullPointerException
at some.random.package.SomeClass
at another.random.package.SomeOtherClass
at ...

You could get something more like:

Crash detected :(
Cause:
A mod attempted to access something that doesn't exist.
Most likely responsible:
SomeMod
What you can try:
1. Update SomeMod
2. Check its dependencies
3. Test without the mod

The idea is to make debugging feel less like deciphering ancient runes :D
